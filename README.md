# BirthChart
Телеграм бот для созданее натальной картой. Будут использованы легкие LLM для создания отчета. И расчет данных с карт NASA для получения более точных данных.

# Бот день  2
Добавлен кнопочное меню в сообщении. Добавлен класс для изменения формата картинки под телеграм. Добавлены функции обработки кнопки расчета натальной карты. В данный момент пользователь может получить координаты планет со знаками задиака.

# Астрономия день 1

Были перепробовано большое количество API для поиска координат планет для дальнейшего подсчета данных и вычеслений под натальную карту. Большенство API выдают положение планет не относительно Земли поэтому были трудности. Сейчас с помошью `pyswisseph` был достигнут результат. Я получил все планеты с градусами и знаки задиака в которых они находяться. 

Добавил класс по определения координат города и его UTC так как это необходимые данные для подсчета карты. В класе 2 функции первая определяет координаты по полученному городу на русском языке. Втораяч получает UTC относительно координат этого города.
